# 社内書式アプリ（一般社内書類）

`★一般社内書類(2026.06.11)` のExcel書式をWebアプリ化したもの。入力して印刷し、紙で回送する運用。

- フレームワークなし・ビルド不要の静的サイト（GitHub Pages 等にそのまま置ける）
- 全帳票で同じレイアウト：上部にタイトル・日付・押印欄、下部にロゴ（YES＋株式会社 雄電社）
- 入力値はブラウザの localStorage にだけ保存（`shoshiki:<id>`）。サーバー送信なし

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 帳票一覧 |
| `form.html?id=04` | 帳票画面（`forms/04.js` を読み込んで描画） |
| `list.html` | 配布用一覧（リンク＋QR、A4印刷→PDF化）。`?base=<公開URL>` でURLを差し替え可 |
| `assets/app.js` | 共通レンダラー（項目表・明細表・押印欄・自動計算・下書き保存） |
| `assets/app.css` | 共通デザイン・印刷設定 |
| `assets/codes.js` | 登録メモ類で共通のコード表（建物用途・構造など） |
| `assets/date-stamp.js` | 丸型デート印（SVG）。伝票アプリの date-stamp.js と同じレイアウト |
| `forms/catalog.js` | 一覧に出す帳票（番号・名称） |
| `forms/<id>.js` | 帳票ごとの項目定義 |

## 帳票の追加・修正

`forms/<id>.js` に `FORM_DEFS['<id>'] = { code, title, meta, stamps, blocks }` を書き、`forms/catalog.js` に1行足す。
ブロックは `grid`（24分割の項目表）・`table`（明細表、合計・自動計算）・`free`（記述欄）・`image`（画像貼付）・`notes` など。
既存の帳票定義が書き方の見本。必須記入欄（元Excelの色塗り欄）はラベルに `req: true`。

## 押印欄

- 枠の大きさは全帳票共通（幅16mm・押印部16mm）。帳票ごとの幅指定はしない
- `'承認\n工事本部長\nRE部長'` のように書くと、1行目が見出し、2行目以降（兼務の役職名）は押印部に薄く印字
- 登録済検印は `bottomStamps: ['登録済検印']` で下部（フッターの上）に置く。末尾が注意書きならその横に並ぶ
- 押印欄が多くタイトルが入らないときは、タイトルの文字を自動で縮めて1行に収める

## 本人欄のデート印

- 帳票定義の `selfStamp: '発行'` で指定した押印欄にだけ、デート印を自動表示（承認・確認欄は手押しのまま）
- 苗字・役職・色はツールバーの「押印設定」で登録。全帳票共通で localStorage の `shoshiki:_stamp` に保存
- 日付は帳票の `date` 項目（`stampDate` で変更可）、未入力なら今日
- 役職の扱い・色の初期値（課長以下=黒、工事長以上=朱、支店長=事業所名）は伝票アプリと同じ
- 般-05 は氏名横の「印」欄に押す（grid 項目に `stampCell: true`）
- 印の大きさは全帳票共通（直径14.4mm）。小さい欄でははみ出す
